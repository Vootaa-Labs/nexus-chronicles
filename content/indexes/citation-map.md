# Citation Map / 引用关系 / Mapa de citas

This page tracks how one essay grows into other essays, languages, and viewpoints.

这个页面用于追踪一篇文章如何延展成更多语言与更多视角的文章。

Esta pagina rastrea como un ensayo se expande hacia otros ensayos, idiomas y puntos de vista.

## How Citation Works / 引用如何运作 / Como funciona la citacion

1. One language can publish an original essay.
2. Another language can cite it, summarize it, challenge it, or extend it.
3. A later essay can become a new source node rather than a subordinate translation.

1. 一个语言区可以先发布原创文章。
2. 另一个语言区可以引用、总结、回应或延展它。
3. 后续文章可以继续长成新的源头节点，而不是原文的附属翻译件。

1. Una zona de idioma puede publicar un ensayo original.
2. Otra zona puede citarlo, resumirlo, cuestionarlo o ampliarlo.
3. Un ensayo posterior puede convertirse en un nuevo nodo fuente en lugar de una traduccion subordinada.

## Relationship Types / 引用类型 / Tipos de relacion

| Pattern | English | 中文 | Espanol |
|---|---|---|---|
| `original -> citation` | summary or contextualized retelling | 摘要式引用或语境化转述 | cita con resumen o relectura contextual |
| `original -> response` | agreement, disagreement, or challenge | 回应、质疑或对照写作 | respuesta, desacuerdo o contraste |
| `original -> language expansion` | new native-language essay from a prior source | 基于前文发展出的新母语文章 | nuevo ensayo en otra lengua a partir de una fuente previa |
| `essay -> essay cluster` | one theme branching into multiple sub-essays | 一个主题扩展成多篇子文章 | un tema que se abre en varios subensayos |

## Reader Value / 读者价值 / Valor para lectores

1. Citation pages show where an argument started and how it changed.
2. 引用关系页帮助读者看到观点从哪里开始、又如何被改写。
3. El mapa de citas permite ver donde empezo una idea y como fue transformada.
