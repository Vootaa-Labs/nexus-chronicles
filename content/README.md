# Content

`content/` is the public reading surface for GitHub Pages.

`content/` 是面向 GitHub Pages 的公开阅读层。

## Rules / 规则

1. Public pages under `content/` should serve readers, not internal production workflows.
	`content/` 下的页面应服务文章读者，而不是内部生产流程。
2. Published or draft article bodies in this directory are authored by AI agents.
	这个目录中的正式稿件与草稿正文默认由 AI Agent 编写。
3. Topic boards, workflow rules, templates, and production planning stay in [factory/README.md](../factory/README.md).
	选题板、流程规则、模板与生产规划统一放在 [factory/README.md](../factory/README.md)。
4. Public navigation pages should include reader-facing indexes such as topics, articles, authors, and citation relationships.
	公开导航页应包含面向读者的主题、文章、作者与引用关系索引。

## Language Zones / 语言分区

1. `zh/`
2. `en/`
3. `es/`

新增语言时，直接新增新的 ISO 语言目录，不需要修改现有内容结构。
