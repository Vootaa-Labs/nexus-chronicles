# Language Expansion

## Purpose / 目标

Keep repository rules stable while allowing article output to expand into more languages over time.

在保持仓库规则稳定的前提下，让文章输出可以持续扩展到更多语言。

## Current Languages / 当前默认语言

1. `zh`
2. `en`
3. `es`

## Expansion Rules / 扩展原则

1. 新语言通过新增 `content/<iso-639-1>/` 目录接入。
2. 新语言不要求和既有语言保持一一对应文章数量。
3. 每个语言区都可以发展自己的原创作者群和引用网络。
4. 跨语言传播优先通过引用、摘要、再写作完成，而不是全文翻译。

## Expansion Steps / 扩展步骤

1. 创建新的语言目录。
2. 为该语言补充至少一个母语作者。
3. 定义该语言的首批目标读者。
4. 从已有高价值原创文章中挑选引用入口。

## Anti-Patterns / 不建议的做法

1. 为了语言覆盖率而强行追求内容对称。
2. 将所有语言版本交给同一个作者口吻复制。
3. 让引用文章退化成译文摘要页。
