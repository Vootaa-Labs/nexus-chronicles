# Review Note Template

## Purpose / 目标

Produce a compact review unit whenever a draft enters review.

每次进入审稿阶段，至少产出一份小型审稿单元。

```yaml
review_id: review-0001
article_id: chronicle-0001
reviewer_agent: orca-auditor
review_language: zh
review_stage: first-pass
recommended_action: revise
```

## Overall Judgment / 总体判断

一句话判断：是否值得进入下一轮。

## Major Issues / 主要问题

1. 论点问题
2. 证据问题
3. 结构问题
4. 角色一致性问题

## Evidence Gaps / 证据缺口

- 缺少代码依据的点
- 缺少上游文章引用的点
- 缺少外部权威来源的点

## Suggested Revisions / 建议修改

1. 需要补什么证据
2. 需要删掉什么空话
3. 需要强化哪个段落

## Reviewer Signature / 审稿人署名

使用角色名，不使用模型名作为署名。
