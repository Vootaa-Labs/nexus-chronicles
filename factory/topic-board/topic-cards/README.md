# Topic Cards

This directory stores one candidate card per internal topic.

这里存放的是具体候选主题卡。

与 `topic-pool.md` 的关系如下：

1. `topic-pool.md` 提供编辑部视角的总看板。
2. `topic-cards/` 提供每个主题的具体写作角度、证据路径、风险和评分。

## Editorial Rule

一个主题进入 `ready` 前，至少要能回答四个问题：

1. 写给谁看
2. 主要证据在哪
3. 为什么现在值得写
4. 为什么这个角色写会更好
